Function kits package what a Firebase Extension did as ordinary 2nd gen Cloud Functions for Firebase, so the capability deploys and is managed like the rest of a developer's functions.

**Why it matters.** The Firebase Extensions service shuts down on March 31, 2027. Function kits turn that shutdown into an upgrade: developers keep what their extensions did, and Firebase has one serverless product to maintain instead of two.

**My role.** Led the replacement. Set the strategy with senior leadership against external deadlines, closed the feature gaps, and shipped tooling and an agent skill that migrate extension code and deployments. Then trained the owning team and handed it off.
