Google's open-source framework for building AI features into apps.

**Why it matters.** Genkit for Node.js reached 1.0 in February 2025 and was declared ready for production use.

**My role.** Embedded with the team for 1.0. Redesigned the HTTP bindings so switching web frameworks takes one line of code and middleware works everywhere. Built Next.js support, rebuilt the Express and Cloud Functions for Firebase bindings on the new design, and hardened streaming. Later made Genkit telemetry work on App Hosting with zero configuration.
