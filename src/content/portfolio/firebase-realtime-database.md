Firebase's original product, a hosted JSON database that syncs changes to every connected client in realtime.

**My role.** Joined after the Google acquisition and worked on reliability, including the migration into Google Cloud, a zero-downtime database fleet upgrade, failover, and monitoring. Added promise support and, later, atomic counters to the SDKs. Its event pipeline, which I built, became the first event source for Cloud Functions for Firebase.
