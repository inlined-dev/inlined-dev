Managed hosting for dynamic web apps. Push to GitHub and App Hosting builds with Cloud Build, serves on Cloud Run, and caches in Cloud CDN, with built-in support for Next.js and Angular.

**Why it matters.** Firebase's answer to full-stack frameworks, so server-rendered apps no longer have to leave Firebase. Announced at Google I/O 2024.

**My role.** Wrote the initial design, then led the team that built and launched it: up to 16 engineers and two agencies.
