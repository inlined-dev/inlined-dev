Managed hosting for dynamic web apps. Push to GitHub and App Hosting builds with Cloud Build, serves on Cloud Run, and caches in Cloud CDN, with built-in support for Next.js and Angular.

**Why it matters.** Google's first all-inclusive solution for full-stack web hosting. One product takes a repository from push to a globally served app. Announced at Google I/O 2024, it became [generally available at Google Cloud Next 2025](https://firebase.blog/posts/2025/04/apphosting-general-availability/).

**My role.** Started as its tech lead, deciding the scope and the broad design. As the team grew to 16 engineers and an agency, I took on smaller technical scope and gradually became a manager first.
