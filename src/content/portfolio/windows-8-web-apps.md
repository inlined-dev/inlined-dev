The platform that let developers build Windows Store apps in HTML and JavaScript, calling the new Windows Runtime (WinRT) APIs directly from script.

**Why it matters.** It made web developers first-class Windows app developers, alongside C++ and .NET, in the release that introduced WinRT, .appx packages, and the Windows Store.

**My role.** Built the host process that runs web apps. It loads WinRT components and brokers privileged calls out of the sandbox. Also consulted first-party requirements to prove WinRT's scope would meet Windows' needs.
