A common envelope for event data, so events can move between clouds, platforms and services without custom glue.

**Why it matters.** The CNCF [graduated CloudEvents in January 2024](https://www.cncf.io/announcements/2024/01/25/cloud-native-computing-foundation-announces-the-graduation-of-cloudevents/). It underpins eventing across Knative, Google's Eventarc and other cloud platforms.

**My role.** Brought the event model behind Cloud Functions for Firebase into a joint effort with serverless.com, then took it to the CNCF. I worked on the 0.1 release, [announced at KubeCon 2018](https://medium.com/@austencollins/introducing-cloudevents-a758c62c76bf), whose launch included my demo, and wrote extensions including sampled rate and auth context.
